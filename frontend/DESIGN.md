# LeadDesk Pro Design System

## Core Identity
**Tagline:** Capture. Track. Convert.
**Aesthetic:** Modern Enterprise SaaS, Neo Brutalism, Minimalism, Developer Tool Aesthetic.
**Vibe:** Premium, Ultra Clean Layout, Handcrafted components, No cheap glassmorphism, No generic shadows.

## Color System
- **Background:** `#050505` (Dark charcoal background)
- **Surface:** `#090909`
- **Card:** `#101010`
- **Elevated Card:** `#151515`
- **Border:** `#232323`
- **Primary Text:** `#F8F8F8`
- **Secondary Text:** `#A1A1AA`
- **Muted Text:** `#71717A`

**Accents:**
- **Blue:** `#3B82F6`
- **Purple:** `#7C3AED`
- **Green:** `#22C55E`
- **Orange:** `#F59E0B`
- **Red:** `#EF4444`

## Typography
- **Headings:** Clash Display (Weight: 700)
- **Body:** General Sans (Weight: 400)
- **Numbers:** IBM Plex Mono
- **Buttons:** General Sans Medium
- **Letter Spacing:** Slightly reduced.

## Spacing & Grid System
- **Grid:** 8pt grid system.
- **Spacing Scale:** 8, 16, 24, 32, 48, 64, 80, 96.
- **Radii:** 
  - Cards: 18px
  - Buttons: 16px
  - Inputs: 16px
  - Sidebar: 20px
- **Layout:** Use breathing room. Nothing should feel cramped.

## Background & Effects
- **Background Details:** Noise texture, very subtle grid, soft radial light, mouse parallax, tiny animated particles, barely visible gradients.
- **Animations:** Framer Motion (Fade, Scale, Slide, Stagger, Hover, Button Ripple, Counter Animation). Soft motion, no bouncing.
